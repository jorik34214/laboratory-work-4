### 2.3-LogicalModel Логічна схема БД моделі даних

У даному розділі представлена логічна схема бази даних для програмного продукту **GaitRecovery Vision**, розроблена у вигляді реляційної моделі за допомогою мови PlantUML.

#### Основні особливості логічної моделі:
* Використано реляційний підхід для представлення даних системи реабілітації ходи.
* Описано структури таблиць для збереження інформації про пацієнтів, вправи, сеанси та кутові вимірювання суглобів.
* Встановлено первинні та зовнішні ключі, а також зв'язки між сутностями.
* Результат моделювання збережено у файлі RelLogicalSchema.puml.
