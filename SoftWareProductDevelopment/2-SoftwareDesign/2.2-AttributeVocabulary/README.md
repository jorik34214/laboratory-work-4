### 2.2-AttributeVocabulary Словник атрибутів об’єктів

Нижче наведено таблицю словника атрибутів об’єктів для концептуальної моделі програмного продукту **GaitRecovery Vision**.

#### Словник атрибутів об’єктів

| Об’єкт | Атрибут | Короткий опис | Тип | Обмеження |
| :--- | :--- | :--- | :--- | :--- |
| **Patient** | прізвище | Прізвище пацієнта | string | довжина від 2 до 50 символів |
| **Patient** | посада | Посада або статус пацієнта | string | довжина до 30 символів |
| **Exercise** | назва | Назва комплексу вправ | string | унікальне значення, до 100 символів |
| **Exercise** | опис | Детальний опис вправи | string | до 500 символів |
| **Session** | дата | Дата проведення сеансу | string | формат ДД.ММ.РРРР |
| **Session** | тривалість | Тривалість сеансу в хвилинах | integer | значення більше 0 |
| **JointMeasurement** | кут вигину | Кут вигину суглоба в градусах | number | від 0 до 180 |
| **JointMeasurement** | асиметрія ходи | Показник асиметрії ходи | number | від 0 до 100 |
| **PhysicalTherapist** | прізвище | Прізвище спеціаліста | string | довжина від 2 до 50 символів |
| **PhysicalTherapist** | категорія | Кваліфікаційна категорія | string | до 30 символів |
