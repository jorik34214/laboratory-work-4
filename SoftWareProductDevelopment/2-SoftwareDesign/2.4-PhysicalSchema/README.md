### 2.4-PhysicalSchema Фізична схема БД моделі даних

У цьому розділі наведено реалізацію фізичної схеми реляційної бази даних для програмного продукту **GaitRecovery Vision**.

#### Основні особливості фізичної схеми:
* Створено SQL-скрипт (DataSchema.sql) для розгортання бази даних у цільовій СУБД.
* Використано стандартні типи даних (VARCHAR, INTEGER, REAL, SERIAL) для всіх атрибутів.
* Налаштовано обмеження цілісності: первинні ключі (PRIMARY KEY), зовнішні ключі (FOREIGN KEY) та перевірки значень (CHECK).
* Для текстових та числових полів впроваджено регулярні вирази (Regex) для забезпечення валідації вхідних даних.
