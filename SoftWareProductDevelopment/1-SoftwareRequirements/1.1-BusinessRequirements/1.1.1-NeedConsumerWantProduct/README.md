### Вимоги до бізнес-процесів

#### Сценарний клас застосування HCI:
Тілесно-орієнтована людино-комп’ютерна взаємодія / Виконання реабілітаційних фізичних вправ (вправи на відновлення ходи).

#### Клас програмного продукту (ПП):
Інтерактивна система комп'ютерного зору для реабілітації рухової активності та відновлення ходи (*Vision-based Gait Rehabilitation System*).

#### Цільова група споживачів:
Пацієнти на етапі реабілітації після травм опорно-рухового апарату чи операцій нижніх кінцівок; літні люди з порушеннями координації ходи; реабілітаційні центри та фізичні терапевти.

#### Варіанти бажань споживача:
| Бажання | Обґрунтування |
| :--- | :--- |
| **1. Автоматичний контроль правильної постави та симетрії кроків** | Користувач хоче бачити об'єктивні показники виконання вправ без постійної присутності тренера. |
| **2. Зручний інтерфейс на базі звичайної веб-камери** | Відсутність потреби купувати дорогі датчики — достатньо камери смартфона або ПК. |
| **3. Персоналізований план реабілітаційних вправ** | Потреба у поступовому збільшенні навантаження відповідно до динаміки відновлення. |
| **4. Візуальна та звукова індикація помилок у реальному часі** | Миттєве сповіщення про неправильне положення тіла для запобігання травмам. |
| **5. Ведення статистики прогресу та експорт звітів для лікаря** | Бажання пацієнта бачити покращення результатів, а лікаря — аналізувати динаміку. |

#### Потреби за ієрархією Маслоу:
| Бажання | Потреба за Маслоу | Обґрунтування |
| :--- | :--- | :--- |
| Автоматичний контроль правильної постави та симетрії кроків | **Потреба в безпеці** | Мінімізація ризику повторного травмування через неправильну техніку. |
| Зручний інтерфейс на базі веб-камери | **Фізіологічна потреба / Збереження здоров'я** | Доступність реабілітаційних заходів у домашніх умовах. |
| Персоналізований план реабілітаційних вправ | **Потреба в повазі (самореалізація)** | Відчуття контролю над власним здоров'ям та стабільний прогрес. |
| Візуальна та звукова індикація помилок | **Потреба в безпеці** | Захист від помилок під час виконання рухових завдань. |
| Ведення статистики прогресу та звітів | **Самовираження / Визнання** | Усвідомлення результатів та успішне досягнення мети реабілітації. |
