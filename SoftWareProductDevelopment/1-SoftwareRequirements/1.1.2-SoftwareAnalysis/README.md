### Аналіз існуючих програмних продуктів

1. **PhysiApp** — мобільна та веб-платформа для домашніх реабілітаційних вправ з відеоінструкціями. Апаратне забезпечення: смартфон/веб-камера, мобільний додаток.
2. **Kine Rehab** — спеціалізована система на базі комп'ютерного зору для аналізу амплітуди рухів та ходи. Апаратне забезпечення: камера (RGB-D або стандартна веб-камера), ПК/планшет.
3. **Rehab Guru** — платформа для створення програм реабілітації з відстеженням активності пацієнтів. Апаратне забезпечення: веб-інтерфейс, мобільні пристрої.
