### Аналіз існуючих програмних продуктів

#### 1. PhysiApp
- **Назва ПП:** PhysiApp
- **Веб-ресурс:** [https://www.physiapp.com](https://www.physiapp.com)
- **Виявлені властивості ПП:** 
  - Надання відеоінструкцій до реабілітаційних вправ.
  - Можливість відстеження виконання завдань пацієнтом.
  - Інтеграція зі зв'язком між пацієнтом та лікарем (чат, нагадування).
- **Виявлені властивості апаратного забезпечення / матеріальних об’єктів:** 
  - Використання мобільних пристроїв (смартфонів, планшетів) або персональних комп'ютерів.
  - Використання фронтальної камери для перегляду контенту та фіксації зворотного зв'язку.

#### 2. Kine Rehab
- **Назва ПП:** Kine Rehab
- **Веб-ресурс:** [https://kinerehab.com](https://kinerehab.com)
- **Виявлені властивості ПП:** 
  - Автоматизований аналіз амплітуди рухів за допомогою комп'ютерного зору.
  - Оцінка симетрії ходи та рухової активності в реальному часі.
  - Генерація звітів для лікарів-реабілітологів.
- **Виявлені властивості апаратного забезпечення / матеріальних об’єктів:** 
  - Використання стандартних веб-камер або RGB-D сенсорів (камер глибини).
  - Підключення до ПК або планшета з підтримкою обробки відеопотоку.

#### 3. Rehab Guru
- **Назва ПП:** Rehab Guru
- **Веб-ресурс:** [https://rehabguru.com](https://rehabguru.com)
- **Виявлені властивості ПП:** 
  - Проєктування та призначення індивідуальних програм реабілітації.
  - Інтерактивна бібліотека вправ із налаштуванням параметрів навантаження.
  - Моніторинг динаміки відновлення пацієнтів.
- **Виявлені властивості апаратного забезпечення / матеріальних об’єктів:** 
  - Хмарна веб-платформа, що взаємодіє з будь-якими пристроями через інтернет-браузер.
  - Мобільні додатки для пацієнтів.
