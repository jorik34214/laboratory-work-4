### 1.3.1 Опис функціональних вимог 

У даному розділі наведено дворівневий опис функціональних вимог для програмного продукту **GaitRecovery Vision**, сформований на основі BDD-специфікацій, створених у Лабораторній роботі №1.

#### Перелік функціональних вимог до програмного продукту

| Ідентифікатор вимоги | Короткий опис вимоги | BDD-специфікація (User Story) | Тип джерела (I want to / In order to) |

| **FR-01.1** | Система повинна зчитувати відеопотік з веб-камери користувача для відстеження опорних точок тіла під час виконання вправ. | Feature 1: Real-time gait analysis via camera | I want to |
| **FR-01.2** | Система повинна обчислювати кути вигину колінного та кульшового суглобів у реальному часі. | Feature 1: Real-time gait analysis via camera | I want to |
| **FR-01.3** | Система повинна надавати візуальний зворотний зв'язок користувачу про відхилення симетрії ходи під час вправи. | Feature 1: Real-time gait analysis via camera | I want to |
| **FR-01.4** | Система повинна фіксувати правильність виконання елементів вправи для запобігання травмуванню та зменшення навантаження на суглоби. | Feature 1: Real-time gait analysis via camera | In order to |
