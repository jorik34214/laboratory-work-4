### 1.3.1 Опис функціональних вимог (FR)

| ID вимоги | Назва вимоги | Опис функціональної вимоги | Пріоритет |
| :--- | :--- | :--- | :--- |
| **FR-1** | Вибір комплексу вправ | Система повинна надавати пацієнту можливість вибору індивідуального комплексу вправ на відновлення ходи із призначеного списку. | Високий |
| **FR-2** | Активація камери для трекінгу | Система повинна активувати та налаштовувати позиціонування пристрою введення (веб-камери) для розпізнавання рухів тіла. | Високий |
| **FR-3** | Відстеження поз і кроків у реальному часі | Система повинна збирати відеопотік з камери та виконувати pose estimation для аналізу постави, довжини кроків і симетрії руху пацієнта. | Високий |
| **FR-4** | Формування звукового та візуального зворотного зв'язку | Система повинна генерувати миттєві сповіщення (візуальні підказки на екрані або звукові сигнали) у разі виявлення відхилень від правильної техніки виконання вправи. | Середній |
| **FR-5** | Збереження та аналіз результатів сеансу | Система повинна автоматично зберігати параметри завершеного сеансу тренування для забезпечення оцінки прогресу відновлення пацієнта. | Високий |
| **FR-6** | Призначення плану реабілітологом | Система повинна дозволяти фізичному терапевту створювати, редагувати та призначати персоналізовані параметри тренувань для конкретного пацієнта. | Високий |
