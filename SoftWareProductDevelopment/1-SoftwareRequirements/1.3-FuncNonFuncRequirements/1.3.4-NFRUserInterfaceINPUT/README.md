### 1.3.4 Опис вимог до INPUT-потоків інтерфейсу користувача (NFR-IN)

| NFR ID | Пов'язаний OUTPUT ID | Назва події / дії INPUT | Опис вхідного потоку та параметрів взаємодії |
| :--- | :--- | :--- | :--- |
| **NFR-IN-1** | NFR-OUT-1 | Клік миші / Натискання на сенсорному екрані | Натискання кнопки «Розпочати сеанс» або «Призупинити» у головному меню. |
| **NFR-IN-2** | NFR-OUT-2 | Налаштування положення камери (Системна подія) | Автоматичне або ручне підтвердження готовності камери до захоплення рухів (роздільна здатність мінімум 720p при 30 fps). |
| **NFR-IN-3** | NFR-OUT-3 | Голосова або ручна команда завершення | Натискання кнопки «Завершити сеанс» для збереження результатів у базі даних. |
