### 1.3.5 Основні нефункціональні вимоги

#### 1. Вимоги до продуктивності (Time Performance)
- Затримка (latency) обробки відеопотоку модулем комп'ютерного зору не повинна перевищувати 50 мс для забезпечення плавного зворотного зв'язку в реальному часі.
- Час завантаження інтерфейсу тренування та ініціалізації камери - не більше 3 секунд.

#### 2. Вимоги до інтерфейсу із зовнішніми пристроями
- Підтримка стандартних USB-веб-камер або вбудованих камер смартфона/ПК з роздільною здатністю не нижче HD (1280x720).
- Сумісність із відтворюючими аудіопристроями (динаміки, навушники) для подачі звукових попереджень.

#### 3. Вимоги до програмного інтерфейсу
- Наявність RESTful API для взаємодії між клієнтською частиною (мобільний/веб-додаток) та серверну частиною (Spring Boot).
- Використання бібліотек комп'ютерного зору (наприклад, OpenCV або MediaPipe) для обробки поз.

#### 4. Вимоги до інтерфейсу передачі даних
- Передача відеопотоку та телеметрії здійснюється за зашифрованими протоколами (HTTPS / WSS).
- Зберігання звітів про сеанси у форматі JSON у реляційній базі даних PostgreSQL.
