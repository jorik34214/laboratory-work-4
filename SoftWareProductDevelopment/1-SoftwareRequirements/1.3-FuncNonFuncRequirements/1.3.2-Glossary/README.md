### 1.3.2 Глосарій термінів

| № | Термін | Визначення / Пояснення |
| :--- | :--- | :--- |
| **1** | **Gait (Хода)** | Циклічний руховий акт, що характеризується послідовними рухами нижніх кінцівок під час пересування. |
| **2** | **Pose Estimation (Оцінка по́зи)** | Технологія комп'ютерного зору для визначення координат суглобів і положення частин тіла людини на зображенні або відео. |
| **3** | **Симетрія кроків** | Рівномірність навантаження та амплітуди рухів між лівою і правою кінцівкою під час ходьби. |
| **4** | **Фізичний терапевт (Реабілітолог)** | Медичний фахівець, який розробляє та контролює програму відновлення рухових функцій пацієнта. |
| **5** | **UI (User Interface)** | Інтерфейс користувача, через який пацієнт взаємодіє з системою реабілітації. |
