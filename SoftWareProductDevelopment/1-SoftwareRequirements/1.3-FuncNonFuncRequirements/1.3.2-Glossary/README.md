### 1.3.2 Глосарій термінів

У даному розділі наведено глосарій спеціальних термінів та скорочень, які використовуються безпосередньо в описі функціональних вимог для програмного продукту **GaitRecovery Vision**.

#### Глосарій термінів

| Термін / Скорочення | Визначення |
| :--- | :--- |
| **Відеопотік (Video Stream)** | Послідовність цифрових кадрів, що безперервно надходять від веб-камери у реальному часі для комп'ютерного аналізу. |
| **Опорні точки тіла (Body Keypoints)** | Анатомічні орієнтири на тілі людини (суглоби, кінцівки), що визначаються алгоритмами комп'ютерного зору. |
| **Симетрія ходи (Gait Symmetry)** | Співвідношення біомеханічних параметрів рухів лівої та правої нижніх кінцівок під час ходьби. |
| **Кут суглоба (Joint Angle)** | Кут між анатомічними сегментами тіла у ділянці колінного або кульшового суглоба, що вимірюється в градусах. |
| **Зворотний зв'язок (Feedback)** | Візуальне або звукове повідомлення системи користувачеві про точність виконання вправи. |
| **Метрики відтворення ходи (Gait Metrics)** | Кількісні показники якості ходи (амплітуда рухів, темп, симетрія кроку). |
| **Фізичний терапевт (Physical Therapist)** | Спеціаліст з реабілітації, який аналізує дані пацієнта та коригує план лікування. |
